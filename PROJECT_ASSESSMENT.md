# Public project assessment

Assessment date: 2026-08-23

The portfolio selection is based on the public repositories at
[github.com/MrQwerty13](https://github.com/MrQwerty13). Scores combine four
dimensions: implementation depth (40%), architecture (20%), engineering quality
and documentation (20%), and product polish (20%). A score of 8.0 or higher is
featured in the portfolio.

| Project | Score | Description and conclusion |
| --- | ---: | --- |
| CupIT | **9.5** | Local-first cafe analytics with domain models, a replaceable data provider, Flask API, Next.js dashboard, private Ollama integration, Docker, and broad tests. The clearest end-to-end product in the account and the strongest portfolio lead. |
| FriedSausages | **8.7** | Security operations product spanning assets, vulnerabilities, compliance, archives, reports, a React dashboard, PostgreSQL-oriented backend, migrations, scripts, Docker, and tests. Ambitious and technically substantial; repository hygiene is held back by committed dependencies. |
| Chatic | **8.5** | Private web messenger with accounts, profiles, chat search, typing state, WebSocket realtime behavior, polling fallback, and deployment documentation. Strong feature completeness and clean separation between routes, services, models, storage, and UI. |
| Aftertaste | **8.2** | Deployed bilingual social tasting journal with accounts, posts, reactions, comments, moderation, themes, SQLite persistence, and migration from legacy storage. A complete and distinctive product; committed environment and editor artifacts reduce maintainability. |
| TaskTrackerPyVersion | **8.0** | Task manager with shared business logic across Flask web and console interfaces, atomic JSON writes, legacy migration, and a compact API. Thoughtful layering makes a small product more convincing, though automated tests and repository cleanup are still needed. |
| from_json_to_graphix | **7.4** | Flask utility that uploads or creates JSON, normalizes it, analyzes it, and produces reports and graphs. Useful working scope, but the documentation and test strategy are too light for the featured threshold. |
| SexTrack | **6.8** | Native SwiftUI journal concept with local persistence, localization, statistics, and privacy-first product framing. The main source directory is committed as an unresolved Git link, so the public repository cannot currently demonstrate the implementation described by its README. |
| 2D_3D_Engine | **5.5** | Well-considered plan for a shared C++20 2D/3D room-design engine using SDL3 and bgfx. The architecture and roadmap are promising, but the repository currently contains planning documents rather than an implemented engine. |
| myFirstProject | **4.2** | A compact first Python project with Docker and CI configuration. Valuable as a learning milestone, but its very small implementation and minimal documentation do not yet support a portfolio case study. |
| FilesForRaspi | **3.5** | Two small Python scripts intended for Raspberry Pi use. The repository lacks a README, setup instructions, and enough context to judge the intended product or reliability. |
| myWebPage | **3.0** | This portfolio repository began as a to-do and license only. It is intentionally scored on its pre-development state; the current ASP.NET Core implementation is the work that will raise it. |
| FarmAtRoblox | **1.5** | Roblox game placeholder containing only a license in the public default branch. There is not yet enough implementation or documentation to evaluate as a product. |

## Featured selection

CupIT, FriedSausages, Chatic, Aftertaste, and TaskTrackerPyVersion meet the 8.0+
threshold and form the first portfolio release.
